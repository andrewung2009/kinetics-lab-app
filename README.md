# Unit 4 Lab

A personal daily active-recall trainer for A-Level Chemistry Unit 4.

Covers the physical-chemistry topics in the Pearson Edexcel IAL Unit 4
specification (Topics 11–14):

- Kinetics
- Entropy and energetics
- Chemical equilibria
- Acid–base equilibria

Every card is tagged with its specification point and starts with the matching
command word (Define, Calculate, Explain, Deduce, Select, Interpret, and so on).
The deck has 326 cards across 21 sections and covers every subpoint from 11.1 to
14.23. Organic chemistry (Topic 15) is not included.

Open **https://andrewung2009.github.io/kinetics-lab-app/** on a phone and use
*Add to Home Screen* to install it. It works offline after the first load.

This repository contains only the compiled app (HTML, manifest, service worker and icons).
